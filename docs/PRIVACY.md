# TunnelDeck 隐私政策

生效日期：2026 年 8 月 7 日

TunnelDeck Chrome 扩展用于从 Chrome 侧边栏控制用户本机安装的 TunnelDeck 桌面应用。扩展不提供云端账户，不收集分析数据，不展示广告，也不会出售或向第三方传输用户数据。

## 本地处理的数据

为了创建和控制 SSH 本地端口转发，TunnelDeck 会在用户设备上处理：

- SSH 服务器地址、端口和用户名；
- 本地监听地址、端口以及 SSH 服务器可访问的目标地址和端口；
- 用户为连接填写的名称、网页服务类型和重连选项；
- SSH 服务器主机指纹与连接状态；
- 用户主动提供的密码、私钥路径或私钥口令。

Chrome 扩展通过 Chrome Native Messaging 与本机 TunnelDeck 进程通信。普通连接配置保存在桌面应用的本地配置目录中。密码和私钥口令不会写入 Chrome Storage；用户未选择“记住凭据”时，它们只在连接所需的内存中短暂使用。用户主动选择“记住凭据”后，桌面应用会使用操作系统提供的安全凭据存储。

## 网络访问

扩展自身不会连接 TunnelDeck 的开发者服务器，也不会读取用户访问的网页。SSH 连接由用户设备上的桌面应用直接连接到用户指定的 SSH 服务器。只有当用户把某个隧道标记为 HTTP 或 HTTPS 服务，并主动点击“打开网页”时，扩展才会在新标签页打开对应的本地转发地址。

## Chrome 权限

- `nativeMessaging`：与用户明确安装并注册的 TunnelDeck 本机应用通信。
- `sidePanel`：在 Chrome 侧边栏显示隧道管理界面。

扩展不申请浏览历史、所有网站、代理、Cookie、标签页内容或网页注入权限。

## 数据控制与删除

用户可以在 TunnelDeck 中删除连接配置，也可以通过操作系统的凭据管理工具删除已保存凭据。卸载 Native Messaging Host 会停止扩展与桌面应用之间的通信。卸载扩展不会自动删除桌面端配置；卸载桌面应用也不会代表远程 SSH 服务器上的数据被更改。

## 政策变更与联系

如果扩展的数据处理方式发生实质变化，本政策会在发布新版本前更新。隐私或支持问题请联系：support@sparkles-editor.com。
